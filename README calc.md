# Basic Calculator

A simple calculator built with HTML, CSS and vanilla JavaScript.

## Features
- Add, subtract, multiply, divide
- Decimal numbers
- Delete (⌫) and clear (AC)
- Chained operations (e.g. 2 + 3 × 4)
- Keyboard support (0-9, + - * /, Enter, Backspace, Esc)
- Handles divide-by-zero

## How to run
Download or clone this repo and open `index.html` in any browser. No installation needed.
